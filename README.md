# Foto Owl

Foto Owl is a native React Native + TypeScript photo gallery app built for the Foto Owl internship assignment.

## Features

- Local registration and login with validation
- Picsum photo gallery with search, filters, sorting, favorites, and progressive loading
- Image details, full-screen viewer, and native gallery download
- Profile editing, persistent session, and light/dark preference

## Run locally

```bash
npm install
npx expo start
```

For an Android APK, use the `preview` build profile in `eas.json`. The profile is configured for an installable APK.
